# Task 3: Add Cyclone Twig Structure

## Current State

- `storage/src/bitmap/authenticated.rs` uses configurable chunk size with MMR-like structure
- Chunk size is a const generic `N` (bytes per chunk)
- No support for cyclone's fixed twig structure with 3-level active bits tree

## Expected Goal

Add `CycloneTwig` that exactly matches cyclone's twig structure with:
- Fixed 2048 entries per twig
- 256-byte active bits (8 x 32-byte pages)
- 3-level binary tree for active bits authentication

## Rationale

Cyclone's twig structure is fundamentally different from commonware's MMR-like bitmap:
- Fixed structure vs. configurable
- Binary tree vs. MMR peaks
- Level-based hashing vs. position-based

A new type is cleaner than trying to parameterize the existing `BitMap`.

### Step 2: Implement Active Bits Structure

**File**: `storage/src/bitmap/cyclone_twig.rs`

```rust
//! Cyclone-compatible twig structure for QMDB.

use crate::mmr::cyclone_hasher::{
    CycloneMerkleHasher, Hash32, ZERO_HASH32, merkle_node_hash_inplace,
};

/// Number of entries per twig (2^11 = 2048).
pub const LEAF_COUNT_IN_TWIG: u32 = 2048;

/// Bit shift for twig calculations.
pub const TWIG_SHIFT: u32 = 11;

/// Mask for extracting position within twig.
pub const TWIG_MASK: u32 = LEAF_COUNT_IN_TWIG - 1;

/// Active bits for a twig (256 bytes = 2048 bits).
#[derive(Clone, Debug, Default, PartialEq)]
pub struct ActiveBits(pub [u8; 256]);

impl ActiveBits {
    /// Create new active bits with all zeros.
    pub const fn new() -> Self {
        Self([0u8; 256])
    }

    /// Set bit at given offset (0-2047).
    pub fn set_bit(&mut self, offset: u32) {
        debug_assert!(offset < LEAF_COUNT_IN_TWIG);
        let byte_idx = (offset / 8) as usize;
        let bit_idx = offset % 8;
        self.0[byte_idx] |= 1 << bit_idx;
    }

    /// Clear bit at given offset.
    pub fn clear_bit(&mut self, offset: u32) {
        debug_assert!(offset < LEAF_COUNT_IN_TWIG);
        let byte_idx = (offset / 8) as usize;
        let bit_idx = offset % 8;
        self.0[byte_idx] &= !(1 << bit_idx);
    }

    /// Get bit at given offset.
    pub fn get_bit(&self, offset: u32) -> bool {
        debug_assert!(offset < LEAF_COUNT_IN_TWIG);
        let byte_idx = (offset / 8) as usize;
        let bit_idx = offset % 8;
        (self.0[byte_idx] >> bit_idx) & 1 == 1
    }

    /// Get 32-byte page at given index (0-7).
    pub fn get_page(&self, page_num: usize) -> &[u8; 32] {
        debug_assert!(page_num < 8);
        self.0[page_num * 32..(page_num + 1) * 32]
            .try_into()
            .unwrap()
    }
}
```

### Step 3: Implement Twig Structure

**File**: `storage/src/bitmap/cyclone_twig.rs` (continued)

```rust
/// A twig in the cyclone merkle tree.
///
/// Each twig manages 2048 entries with:
/// - Left subtree: entry hashes (levels 0-11)
/// - Right subtree: active bits (levels 8-10)
/// - Combined root at level 11
#[derive(Clone, Debug, PartialEq)]
pub struct Twig {
    /// Level 8 hashes of active bits tree (4 nodes).
    pub active_bits_mtl1: [Hash32; 4],

    /// Level 9 hashes of active bits tree (2 nodes).
    pub active_bits_mtl2: [Hash32; 2],

    /// Level 10 hash of active bits tree (1 node).
    pub active_bits_mtl3: Hash32,

    /// Root of left subtree (entry hashes).
    pub left_root: Hash32,

    /// Combined twig root.
    pub twig_root: Hash32,
}

impl Default for Twig {
    fn default() -> Self {
        Self::new()
    }
}

impl Twig {
    /// Create new twig with all zeros.
    pub const fn new() -> Self {
        Self {
            active_bits_mtl1: [ZERO_HASH32; 4],
            active_bits_mtl2: [ZERO_HASH32; 2],
            active_bits_mtl3: ZERO_HASH32,
            left_root: ZERO_HASH32,
            twig_root: ZERO_HASH32,
        }
    }

    /// Sync level 8 node at position (0-3).
    pub fn sync_l1(&mut self, pos: usize, active_bits: &ActiveBits) {
        debug_assert!(pos < 4);
        let left_page = active_bits.get_page(pos * 2);
        let right_page = active_bits.get_page(pos * 2 + 1);
        merkle_node_hash_inplace(
            8,
            &mut self.active_bits_mtl1[pos],
            left_page,
            right_page,
        );
    }

    /// Sync level 9 node at position (0-1).
    pub fn sync_l2(&mut self, pos: usize) {
        debug_assert!(pos < 2);
        merkle_node_hash_inplace(
            9,
            &mut self.active_bits_mtl2[pos],
            &self.active_bits_mtl1[pos * 2],
            &self.active_bits_mtl1[pos * 2 + 1],
        );
    }

    /// Sync level 10 node.
    pub fn sync_l3(&mut self) {
        merkle_node_hash_inplace(
            10,
            &mut self.active_bits_mtl3,
            &self.active_bits_mtl2[0],
            &self.active_bits_mtl2[1],
        );
    }

    /// Sync twig root (level 11).
    pub fn sync_top(&mut self) {
        merkle_node_hash_inplace(
            11,
            &mut self.twig_root,
            &self.left_root,
            &self.active_bits_mtl3,
        );
    }

    /// Full sync of active bits tree from bits.
    pub fn sync_active_bits(&mut self, active_bits: &ActiveBits) {
        for i in 0..4 {
            self.sync_l1(i, active_bits);
        }
        for i in 0..2 {
            self.sync_l2(i);
        }
        self.sync_l3();
    }

    /// Full sync including twig root.
    pub fn sync_all(&mut self, active_bits: &ActiveBits) {
        self.sync_active_bits(active_bits);
        self.sync_top();
    }
}
```
